# Previous type icons

Copies of the cardio and bodyweight type icons as they were in 1.0.0 (`res/drawable/ic_cardio.xml`,
`res/drawable/ic_bodyweight.xml`), kept before they were replaced by the Tabler "run" and
"jump-rope" icons. To use one again, copy it back into `app/src/main/res/drawable/`.

The strength type icon (`ic_fitness.xml`) was not replaced and is still in use.
